◆ loadString()

void Tape::loadString ( std::string_view input_word,
int64_t start_position = 0 )

Загружает входное слово на ленту, предварительно полностью очищая её.

Поддерживаются произвольные знаковые start_position (включая отрицательные). Если входное слово содержит blank-символы, соответствующие позиции остаются незанятыми («дырками»).

Parameters
input_wordСтрока для загрузки.
start_positionКоордината начального символа (по умолчанию 0).
Exceptions
std::invalid_argumentЕсли во входной строке встретился символ вне алфавита.

◆ toString()

std::string Tape::toString ( ) const
nodiscard

Формирует срез значащей части ленты от min_pos до max_pos.

Любые незаписанные «дырки» между крайними символами подменяются на blank-символ. Если лента пуста, возвращается пустая строка.

Записывает символ в указанную позицию.
