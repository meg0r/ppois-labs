Detailed Description

Двусторонняя бесконечная разреженная лента машины Тьюринга.

Координаты ячеек задаются знаковым целым int64_t. Неинициализированные ячейки неявно содержат Alphabet::getBlank().

Инвариант: во внутренней таблице cells_ хранятся ТОЛЬКО символы, отличные от blank. Запись blank-символа приводит к удалению ячейки.
