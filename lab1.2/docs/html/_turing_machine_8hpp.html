Detailed Description

Фасад симулятора детерминированной машины Тьюринга.

Машина функционирует как вычислитель. Терминальный останов происходит исключительно в двух случаях:

  1. Достигнуто терминальное halt-состояние (HaltedByState).
  2. В таблице отсутствует правило для пары (state, symbol) (HaltedNoRule).
