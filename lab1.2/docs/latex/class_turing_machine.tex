Сбрасывает машину в исходное состояние и загружает слово на ленту. 

Очищает ленту, устанавливает позицию каретки, переводит состояние в initial\+\_\+state, обнуляет счетчик шагов и переводит статус в Running (или Halted\+By\+State, если initial == halt).

{\footnotesize\ttfamily \label{class_turing_machine_a5abd5fff93c1ff762615dbdb94a67dda} 
bool Turing\+Machine::\+step (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Выполняет ровно один такт работы машины. 

Если такт успешно выполнен и привел к halt-\/состоянию, счетчик инкрементируется, статус переходит в Halted\+By\+State, метод возвращает false. Если правило перехода отсутствует, никакого действия не совершается: счетчик НЕ инкрементируется, статус переходит в Halted\+No\+Rule, метод возвращает false.

\begin{DoxyReturn}{Returns}
true, если шаг выполнен и машина все еще Running; иначе false. 
\end{DoxyReturn}
