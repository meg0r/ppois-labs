\doxysubsection{Detailed Description}
Фасад симулятора детерминированной машины Тьюринга. 

Машина функционирует как вычислитель. Терминальный останов происходит исключительно в двух случаях:
\begin{DoxyEnumerate}
\item Достигнуто терминальное halt-\/состояние (Halted\+By\+State).
\item В таблице отсутствует правило для пары (state, symbol) (Halted\+No\+Rule). 
\end{DoxyEnumerate}
