\doxysubsection{Detailed Description}
Двусторонняя бесконечная разреженная лента машины Тьюринга. 

Координаты ячеек задаются знаковым целым int64\+\_\+t. Неинициализированные ячейки неявно содержат \doxylink{class_alphabet_ae7d24c5f3b27b5f0a26b8489ec61ff67}{Alphabet::\+get\+Blank()}.

Инвариант: во внутренней таблице cells\_ хранятся ТОЛЬКО символы, отличные от blank. Запись blank-\/символа приводит к удалению ячейки.
